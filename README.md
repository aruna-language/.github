## About

Aruna is an independent general-purpose programming language initiated by **Iky Dev**.

Inspired by the Madurese language, Aruna explores a more natural and accessible approach to programming while maintaining the flexibility and capabilities needed for real-world software development.

Our goal is to create a language that grows with its users — from their first programming experience to advanced software engineering.

## Philosophy

**01 — Accessibility**

Programming should be approachable for everyone, regardless of experience.

**02 — Identity**

A distinctive programming language inspired by the character of the Madurese language.

**03 — Progression**

A learning experience that develops from simple expressions to advanced programming concepts.

## Language Design

Aruna is planned to include:

- A dedicated `.an` source file extension.
- Natural, Madurese-inspired syntax.
- An interpreter and compiler.
- A bytecode virtual machine.
- A standard library.
- Developer tools and learning experiences.
